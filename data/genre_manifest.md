# 코퍼스 장르·규모 현황 (2026-10-22 갱신, 데이터 세션 A-001~A-003)

## 3. 남은 과제
1. 강희 에세이 보충 (현재 4편). 같은 사람 안의 장르 변동(에세이 vs 보고서)을 먼저 재서 근거로 사용
2. 한국어 장르·규모 균형 (강희 개념 노트 5편 제외 검토, 강희 보고서는 IT 리포트라 수영·나경의 인문 보고서와 결이 다름 → 보고서끼리 비교는 참고용)
3. 나경 영어 "Language has contributed…"는 한국어 에세이의 영어판일 수 있음 (중복 여부 확인)
4. 제목: 수영 일부는 초안, 나경은 원문 제목 확정
5. 3번 개인차 확인은 3명 모두 20편 이상이 되었으나 에세이 계열은 강희 4편으로 해석 조심
